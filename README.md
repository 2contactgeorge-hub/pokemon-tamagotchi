# PokéPal HG — ROM Edition

This build uses locally extracted HeartGold follower graphics from the user-provided clean U.S. HeartGold dump.

## ROM assets currently integrated
- Pikachu: 8 directional HGSS overworld frames extracted from `a/0/8/1`.
- Movement switches between front/back/left/right walking frames.
- Pikachu remains completely local/offline once installed.
- Other species still use the previous online fallback until their HGSS mappings are added.

## Run on iPhone
Host this folder on any static HTTPS host (GitHub Pages works), open it in Safari, then Share → Add to Home Screen.

The original ROM is NOT included in this package.
